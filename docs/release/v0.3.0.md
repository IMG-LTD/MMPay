# MMPay v0.3.0

`v0.3.0` is a rescue release that moves MMPay back onto the requested technical
direction: real Soybean Admin frontend assets, Pig-aligned backend boundaries,
and the first P2 merchant/channel management foundation.

## Included

- Rebased `frontend-admin` product UI on Soybean Admin with Naive UI pages for
  dashboard, merchants, and channels.
- Added admin merchant/channel APIs with RBAC checks, idempotency replay,
  credential environment references, RFC 7807 errors, and audit events.
- Added P1/P2 repository, backend, frontend, governance, and local validation
  contracts.
- Kept Docker image behavior as a single Spring Boot app that serves `/` from
  built `frontend-admin` static assets and `/api/*` from the backend.

## Boundaries

- Huifu live payment execution and MP-8 external evidence remain blocked until a
  real sandbox/public-provider run is captured.
- MMPay remains Pig-aligned, not a complete Pig runtime migration.
- License issuance is still relay-only and vendor-controlled outside this
  repository.
