# MMPay v0.8.3

`v0.8.3` is a P5 release-governance hardening patch. It builds on the
`v0.8.2` vendor binding evidence gate and closes the local GA-gate gap around
backup/restore drill evidence.

## Included

- Added `scripts/governance/verify-backup-restore-drill-evidence.mjs` and
  wrapper script to verify backup/restore drill artifacts.
- The verifier enforces deterministic canonical JSON, Ed25519 evidence
  signatures, operator PGP counter-signatures, pinned operator key metadata,
  restore nonce presence, e2e evidence SHA-256 matching, RTO bounds, and
  90-day freshness.
- Wired `scripts/release-gate.sh --ga` to run the drill evidence verifier
  against `docs/release/backup-restore-drill-evidence.md`.
- Added contract coverage for fresh signed drill evidence fixtures and wired
  the verifier into local validation.

## Boundaries

- This is not the `v1.0.0` GA release. The GA gate still requires completed
  external Huifu payment evidence, immutable image digest evidence, real
  backup/restore drill evidence, real vendor binding evidence, upstream
  binding, and remote `v1.*` tag ruleset evidence.
- Placeholder operator keys, placeholder evidence, stale drill evidence, or
  mismatched signatures remain hard failures.
- Live provider calls remain disabled by default through
  `mmpay.provider-live-calls=false`.
