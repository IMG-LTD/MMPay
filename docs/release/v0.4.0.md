# MMPay v0.4.0

`v0.4.0` is the P2 merchant/channel lifecycle preview release. It builds on the
Soybean Admin and Pig-aligned rescue baseline from `v0.3.0`.

## Included

- Added admin PATCH, DELETE, and verify-binding APIs for merchants and channels.
- Preserved soft-delete semantics by archiving merchant/channel rows instead of
  physically deleting them.
- Added credential bind, unbind, fingerprint verification, stale-fingerprint
  conflict reporting, and accepted/rejected audit coverage.
- Connected the Soybean Admin merchant and channel detail pages to update,
  archive, bind/unbind, and verify-binding actions with Naive UI controls.
- Extended local validation and repository contracts so P2 lifecycle behavior is
  covered next to the original CRUD contract.

## Boundaries

- Huifu live payment execution and MP-8 external evidence remain blocked until a
  real sandbox/public-provider run is captured.
- MMPay remains Pig-aligned, not a complete Pig runtime migration.
- License issuance is still relay-only and vendor-controlled outside this
  repository.
