# MMPay v1.0.1 Release Notes

Status: patch release notes prepared

## Purpose

`v1.0.1` is the Docker quick-start patch for the first GA line. The immutable
`v1.0.0` tag was cut before the source Compose files used Spring Boot's
standard datasource environment names, so those artifacts can start Spring Boot
without `SPRING_DATASOURCE_URL` and fail with:

```text
Failed to configure a DataSource
Failed to determine a suitable driver class
```

The v1.0.0 tag remains immutable. This patch release must be built from the
current post-GA commit instead of rewriting that tag.

## Fixed

- Docker Compose now injects `SPRING_DATASOURCE_URL`,
  `SPRING_DATASOURCE_USERNAME`, and `SPRING_DATASOURCE_PASSWORD` directly.
- The app image runs through `deploy/docker-entrypoint.sh`, which fails before
  Spring Boot starts when the datasource or audit HMAC key is missing.
- `scripts/smoke-docker-compose.sh` builds the image, proves bare image startup
  fails explicitly with missing runtime configuration, then boots both standard
  and minimal Compose stacks to `/actuator/health`.
- The local PostgreSQL bootstrap script provisions `mmpay_app_role` so the app
  can keep its `SET ROLE mmpay_app_role` connection guard.
- Admin home view now loads `/api/admin/dashboard` through the shared
  `adminFetch` client (`fetchAdminDashboard`) instead of a raw `fetch`, so the
  request carries `Authorization: Bearer ...` from local storage and the home
  page no longer 401s after a successful login. The contract guards in
  `tests/repository-contract.test.mjs` and
  `frontend-admin/scripts/mmpay-frontend-contract.mjs` were relaxed accordingly
  to require the `fetchAdminDashboard()` call rather than the raw URL literal.

## Validation

Run before publishing or consuming the patch tag:

```bash
bash scripts/smoke-docker-compose.sh
node --test tests/repository-contract.test.mjs tests/p5-release-closure-contract.test.mjs
```

The smoke must not contain the Spring Boot datasource failure text in
`mmpay-app` logs.

## Deployment Note

For source-based deployment, rebuild the image from the patched checkout:

```bash
export MMPAY_AUDIT_HMAC_KEY="$(openssl rand -base64 32)"
docker compose -f deploy/docker-compose.yml down --volumes --remove-orphans
docker compose -f deploy/docker-compose.yml up --build --force-recreate
```

Do not use the old `v1.0.0` app image to validate the Docker quick start.
