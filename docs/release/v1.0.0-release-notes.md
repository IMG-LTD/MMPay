## Included Surface

- P1 foundation: setup, RBAC, audit chain, IAM boundaries, and runtime degraded
  startup blocking for payment mutation surfaces.
- P2 merchant, channel, credential reference, credential binding, binding
  verification, and admin audit workflows.
- P3 payment lifecycle: payment intents, provider callbacks, refunds,
  reconciliation acknowledgement, outbound webhook integrations, delivery logs,
  redispatch, and guarded bulk redispatch.
- P4 license relay: opaque-byte relay delivery, integration management, relay
  logs, evidence snapshot rendering, and strict no-license-signing boundary.
- P5 release closure: GA release gate, image digest evidence, e2e evidence,
  backup/restore drill evidence, vendor binding evidence, v1 tag ruleset
  evidence, and operator runbooks.
