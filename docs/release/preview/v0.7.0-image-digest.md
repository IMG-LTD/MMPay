# v0.7.0 Preview Image Digest

This preview records the evidence procedure for `v0.7.0`. The immutable image
digest is emitted by the release image workflow after the tag is pushed.

Expected image:

- `ghcr.io/img-ltd/mmpay-app:v0.7.0`

Verification command:

```bash
docker buildx imagetools inspect ghcr.io/img-ltd/mmpay-app:v0.7.0
```

The release workflow output is the source of truth for the digest when registry
metadata is not readable by an anonymous client.
