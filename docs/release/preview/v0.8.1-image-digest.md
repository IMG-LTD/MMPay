# v0.8.1 Preview Image Digest

This preview records the evidence procedure for `v0.8.1`. The immutable image
digest is populated after the remote `MMPay Images` workflow publishes the tag.

## Expected Image

- `ghcr.io/img-ltd/mmpay-app:v0.8.1`

## Verification Command

```bash
docker buildx imagetools inspect ghcr.io/img-ltd/mmpay-app:v0.8.1
```

`v1.0.0` GA still requires completed external image digest evidence through
`docs/release/v1.0.0-image-digest-evidence.md`; this preview file is not a GA
substitute.
