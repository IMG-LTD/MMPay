# MMPay v0.8.4

`v0.8.4` is a P5 release-governance hardening patch. It builds on the
`v0.8.3` backup/restore drill evidence gate and closes the local governance gap
around vendor binding PGP key material.

## Included

- Pinned the tracked vendor binding PGP public key in
  `governance/vendor-keys.yaml`.
- Added `governance/vendor-revocations.txt` as the active revocation feed used
  by the vendor binding verifier.
- Tightened `scripts/security-secret-scan.sh` to scan Git-visible files only
  and detect PGP private-key armor headers.
- Added a PGP key governance contract that verifies public-key fingerprint
  pinning and keeps local private/revocation material ignored.
- Documented that only `docs/security/public-key.asc` is safe to commit; local
  private keys and revocation certificates remain local-only.

## Boundaries

- This is not the `v1.0.0` GA release. The GA gate still requires completed
  external Huifu payment evidence, immutable image digest evidence, real
  backup/restore drill evidence, real vendor binding evidence, upstream
  binding, and remote `v1.*` tag ruleset evidence.
- `docs/security/private-key.asc` and
  `docs/security/revocation-certificate.asc` are intentionally ignored and must
  not be committed.
- Live provider calls remain disabled by default through
  `mmpay.provider-live-calls=false`.
