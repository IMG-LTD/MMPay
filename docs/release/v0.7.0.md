# MMPay v0.7.0

`v0.7.0` is the P5 release-closure preview. It builds on the `v0.6.0`
license-relay and integrations baseline and adds the controls required before
the `v1.0.0-rc.N` and `v1.0.0` promotion path can be used.

## Included

- Added RC and GA release-gate modes with explicit external evidence checks.
- Added image digest evidence, vendor binding, registry TLS pin, cosign key,
  operator key, Shamir policy, and restore nonce governance records.
- Added runbooks for backup/restore drills, degraded startup, bootstrap
  compromise rotation, deprecation policy, and upstream evidence flipping.
- Added an audit verifier module for segment restart attestation checks.
- Added degraded-mode guards for refund creation, bulk redispatch, evidence
  snapshot, and license relay forwarding while keeping audit verification
  available.
- Tightened MP-8 evidence handling to accept only `sandbox-with-real-money` or
  `live` provider evidence.

## Boundaries

- This is not the `v1.0.0` GA release. The GA gate still requires external
  Huifu sandbox-with-real-money evidence, image digest/cosign/SLSA evidence,
  vendor PGP binding, and backup/restore drill evidence.
- Live provider calls remain disabled by default through
  `mmpay.provider-live-calls=false`.
- License issuance remains relay-only and vendor-controlled outside this
  repository.
- The immutable GHCR image digest is release evidence only after the remote
  `MMPay Images` workflow completes successfully for tag `v0.7.0`.
