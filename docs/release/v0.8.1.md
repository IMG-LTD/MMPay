# MMPay v0.8.1

`v0.8.1` is a P5 release-governance hardening patch. It builds on the
`v0.8.0` audit-recovery preview and closes the local GA-gate gap around remote
`v1.*` tag immutability evidence.

## Included

- Added `docs/release/v1-tag-ruleset-evidence-template.md` for the external
  GitHub ruleset evidence required before `v1.0.0` GA.
- Added `scripts/governance/verify-v1-tag-ruleset-evidence.sh` to reject
  placeholders and verify the remote ruleset fields against
  `governance/github-rulesets/v1-tags.json`.
- Wired `scripts/release-gate.sh --ga` to fail unless
  `docs/release/v1.0.0-v1-tag-ruleset-evidence.md` exists and verifies.
- Wired the new verifier syntax and contract checks into local validation.

## Boundaries

- This is not the `v1.0.0` GA release. The GA gate still requires completed
  external Huifu payment evidence, immutable image digest evidence,
  backup/restore drill evidence, vendor binding evidence, upstream binding, and
  remote `v1.*` tag ruleset evidence.
- The v1 tag evidence template is not a substitute for installing the ruleset
  in GitHub and capturing external proof. Placeholder values remain hard
  failures.
- Live provider calls remain disabled by default through
  `mmpay.provider-live-calls=false`.
