# Image Digest Evidence

Evidence status: completed-external-evidence

Three OCI images comprise the MMPay v1.0.1 release artifact set.
Each was built by the MMPay Images workflow on commit
c1359fafbdfaa46475527b34c249ee99c6fa7889, pushed to ghcr.io under the
img-ltd organization, and signed keyless via cosign using GitHub OIDC.

The cosign-keyless-oidc attestation hash above is the ghcr.io manifest digest
of the cosign signature artifact for mmpay-app. The signature artifacts for
mmpay-frontend-admin
(sha256:54346f5a76cb175320341e155ed04368b20aaa75a2b55785d0bd6c5ba21d718d)
and mmpay-app-debug-symbols
(sha256:f7971f372c8d238fff4bdb151f3963ff764159577b80fc64237faffdf4fd9dda)
were captured from the same workflow run.

The mmpay-app and mmpay-frontend-admin manifest digests above were
re-fetched from ghcr.io after publication and matched the workflow build
output byte-for-byte. The mmpay-app-debug-symbols digest is taken from the
workflow build output because the package is published with restricted
visibility on ghcr.io.

Compose digest is sha256(deploy/docker-compose.yml) at the same commit and is
re-verified by scripts/governance/verify-image-digest-evidence.sh on every
release-gate invocation. The compose digest is unchanged from
v1.0.0-hotfix.1 because the v1.0.1 patch did not touch
deploy/docker-compose.yml.

Registry immutability proof points to the org-wide GHCR retention policy that
prevents tag overwrites for v1 image lines. Registry SPKI pin rotation is
captured in governance/registry-tls-pins.yaml on a 30 day rotation window.
