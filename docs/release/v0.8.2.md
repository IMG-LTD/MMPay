# MMPay v0.8.2

`v0.8.2` is a P5 release-governance hardening patch. It builds on the
`v0.8.1` remote tag evidence gate and closes the local GA-gate gap around vendor
license relay binding evidence.

## Included

- Added `scripts/governance/verify-vendor-binding-evidence.mjs` and wrapper
  script to verify canonical vendor `BINDING_OK` artifacts.
- The verifier enforces deterministic canonical JSON, evidence SHA-256 matches,
  pinned vendor key metadata, key validity windows, revocation feed checks, and
  detached PGP signature verification.
- Wired `scripts/release-gate.sh --ga` to run the vendor binding verifier
  against `docs/release/vendor-binding/v1.0.0-BINDING_OK.asc`.
- Added contract coverage for a real temporary GPG signature fixture and wired
  the verifier into local validation.

## Boundaries

- This is not the `v1.0.0` GA release. The GA gate still requires completed
  external Huifu payment evidence, immutable image digest evidence,
  backup/restore drill evidence, real vendor binding evidence, upstream
  binding, and remote `v1.*` tag ruleset evidence.
- Placeholder vendor keys or placeholder evidence remain hard failures.
- Live provider calls remain disabled by default through
  `mmpay.provider-live-calls=false`.
