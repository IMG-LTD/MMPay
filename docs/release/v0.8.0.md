# MMPay v0.8.0

`v0.8.0` is the P5 audit-recovery preview. It builds on the `v0.7.0`
release-closure governance baseline and wires segment restart verification into
the runtime audit verify path.

## Included

- Wired the `mmpay-audit-verifier` module into `/api/admin/audit/verify`.
- Extended audit verify output with segment count, segment summaries, and
  segment break assertions while keeping the existing `ok`, `from_id`,
  `to_id`, and `first_break_id` fields.
- Added restore attestation HMAC verification and operator PGP payload binding
  hooks for segment restart checks.
- Added regression tests for attested segment acceptance, missing attestation
  rejection, replayed restore nonce rejection, and invalid attestation HMAC
  rejection.
- Added `scripts/governance/audit-chain-verify-cli.sh` as the operator CLI
  wrapper around the real REST verify endpoint.

## Boundaries

- This is not the `v1.0.0` GA release. The GA gate still requires external
  Huifu sandbox-with-real-money evidence, image digest/cosign/SLSA evidence,
  vendor PGP binding, and backup/restore drill evidence.
- Runtime segment breaks are not accepted by the default verifier unless the
  required nonce, attestation HMAC verifier, and operator PGP verifier are
  explicitly supplied. Missing proof remains a hard verification failure.
- Live provider calls remain disabled by default through
  `mmpay.provider-live-calls=false`.
