# Image Digest Evidence

Evidence status: completed-external-evidence

Three OCI images comprise the MMPay v1.0.2 release artifact set.
Each was built by the MMPay Images workflow on commit
3ac9777efee59e2de8b9d7f04ca384a36f8cf91e, pushed to ghcr.io under the
img-ltd organization, and signed keyless via cosign using GitHub OIDC.

The cosign-keyless-oidc attestation hash above is the ghcr.io manifest digest
of the cosign signature artifact for mmpay-app. The signature artifacts for
mmpay-frontend-admin
(sha256:7a0068be8a340a259b0a3a57cf26460e4d5db823a528e082e1765cf633bf501f)
and mmpay-app-debug-symbols
(sha256:7c286798258d7cbbdb4075b43253672146136a3af97966fe33b0745979c3622c)

captured from the workflow build output. The mmpay-app-debug-symbols digest
is taken from the workflow build output because the package is published with
restricted visibility on ghcr.io.

re-verified by scripts/governance/verify-image-digest-evidence.sh on every
release-gate invocation. The compose digest is unchanged from v1.0.1 because
the v1.0.2 patch did not touch deploy/docker-compose.yml.

Registry immutability proof points to the org-wide GHCR retention policy that
prevents tag overwrites for v1 image lines. Registry SPKI pin rotation is
captured in governance/registry-tls-pins.yaml on a 30 day rotation window.
